# osse-data

Public show catalog for the Osse Android app, served from GitHub Pages at
https://jaykwonovich.github.io/osse-data/. The app downloads these static files with
plain GET requests and sends nothing about the person using it. If a file is missing,
the app falls back to the copy bundled in the app.

## Credits

Show and movie data, images and watch-provider listings come from
[TMDB](https://www.themoviedb.org/). This product uses the TMDB API but is not endorsed
or certified by TMDB. Streaming availability is provided to TMDB by
[JustWatch](https://www.justwatch.com/).
